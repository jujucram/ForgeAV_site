ForgeAV

Antivirus pour Windows

ForgeAV analyse les dossiers, surveille les processus et isole les fichiers suspects avec un scan multithread rapide et efficace.

À propos de ForgeAV

Scanner de fichiers

ForgeAV analyse des dossiers entiers à la recherche de signatures suspectes et de comportements anormaux.

Scan des processus

Surveille les processus en cours pour détecter les menaces actives et protéger votre machine en temps réel.

Multithread performant

Le moteur est optimisé pour exécuter des scans rapides grâce à une architecture multithread adaptée à Windows.

Conçu pour Windows

Écrit en C avec un support Batch, ForgeAV est pensé pour une utilisation sur Windows, portable et facile à compiler.

Fonctionnalités

Scan de dossier

Analyse complète d’un dossier pour détecter les fichiers malveillants et les éléments à risque.

Scan des processus

Inspection des processus en cours pour identifier les menaces actives sur votre système.

Surveillance temps réel

Mode de surveillance continue pour détecter les changements suspects dès qu’ils apparaissent.

Scan multithread

Exécution parallèle des analyses pour accélérer les tests sur les machines modernes.

Quarantaine

Isolation des fichiers suspects pour éviter toute propagation et protéger le système.

Logs détaillés

Journalisation claire des analyses et des évènements pour un suivi précis des scans.

Installation

Compilation et premiers pas

ForgeAV se compile facilement sur Windows. Utilisez `build.bat` ou compilez manuellement avec GCC pour obtenir l’exécutable.

Voir le dépôt GitHub Signaler un problème

Prérequis

  • Windows
  • GCC ou MinGW
  • Exécution en mode administrateur recommandée
  • Machine de test ou environnement virtuel
